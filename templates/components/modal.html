Arguments: open REQUIRED. Alpine expression that is true while open and ASSIGNABLE (a data property), e.g. "confirmOpen". The dialog sets it to false on Escape, backdrop click and the X button. title REQUIRED. Visible heading; labels the dialog (aria-labelledby). description optional text; wired to aria-describedby. size "sm" (24rem), "md" (32rem, default), "lg" (48rem), "sheet" (32rem; below 640px a bottom sheet with a grab handle, rounded top corners, safe-area padding and a 220ms slide-up). Use "sheet" for menus and filters; forms keep the other sizes, which also dock to the bottom below 640px. teleport True (default) moves the dialog to so no ancestor can clip or transform it. return_focus optional CSS selector to focus on close when the opener is hidden or gone (e.g. the opener lived in a menu that closed). Defaults to the previously focused element. Behaviour (implemented by the x-pd-dialog directive in components/_dialog_js.html, loaded by base.html): - On open the first [data-autofocus] element, else the first focusable, else the panel gets focus. - Tab / Shift+Tab wrap inside the dialog; everything outside is inert; the page does not scroll. - Escape closes it; closing returns focus to the opener. For a hand-written dialog (custom layout) put x-pd-dialog="openExpr", role="dialog" aria-modal="true" and aria-labelledby on your own markup; the directive supplies the behaviour. {% endcomment %}{% load common_extras %}{% if teleport %}{% endif %}
