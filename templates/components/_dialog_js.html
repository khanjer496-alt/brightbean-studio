{% comment %} x-pd-dialog - Alpine directive that makes an element behave as a modal dialog while its expression is truthy. Included once by base.html; see components/modal.html for the markup and the {% modal %} tag.
While open: focus moves inside (first [data-autofocus], else first focusable, else the element), Tab wraps, Escape assigns `false` to the expression, every other part of the page is inert (live regions stay announced) and the page scroll is locked. On close focus returns to the element that opened it, or to the data-return-focus selector (comma list allowed; first visible match wins) when that element is gone or hidden. data-dialog-close="expr" overrides the close expression when the open expression is not assignable. Elements with role=alert/status, aria-live or data-pd-backdrop are not made inert. {% endcomment %}
