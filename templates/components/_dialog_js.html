{% comment %} x-pd-dialog - Alpine directive that makes an element behave as a modal dialog while its expression is truthy. Included once by base.html; see components/modal.html for the markup and the {% modal %} tag.
While open: focus moves inside (first [data-autofocus], else first focusable, else the element), Tab wraps, Escape assigns `false` to the expression, every other part of the page is inert (live regions stay announced) and the page scroll is locked. Escape and Tab are handled for the top-most open dialog wherever focus is (e.g. on after a click on plain text), and Escape stops there so outer dialogs and @keydown.escape.window handlers do not also close. On close focus returns to the element that opened it, or to the data-return-focus selector (comma list allowed; first visible match wins) when that element is gone or hidden. data-dialog-close="expr" overrides the close expression when the open expression is not assignable. Elements with role=alert/status, aria-live or data-pd-backdrop are not made inert. This is the only dialog behaviour in the app: do not add page-level Escape/focus-trap handlers for a dialog. Nested dialogs stack, teleported or not: an inner dialog re-enables any ancestor an outer dialog made inert, and everything unwinds in reverse order when it closes. {% endcomment %}
