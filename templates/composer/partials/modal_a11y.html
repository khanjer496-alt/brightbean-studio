{% comment %} Accessible-dialog behaviour for Alpine overlays: `x-a11y-modal="openState"`. Put it (with role="dialog" aria-modal="true" and an aria-label or aria-labelledby) on the overlay element that carries x-show. While the state is truthy it moves focus into the dialog, keeps Tab inside it, closes on Escape and hands focus back to the control that opened it. When closing means more than `state = false`, say how with data-close="expression". Registered once per page (the guard makes repeat includes harmless). Swap for the shared dialog component once templates/components/ has one. {% endcomment %}
