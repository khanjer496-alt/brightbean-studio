(optional initial focus; not the native autofocus, which fires on load)
The expression may be any condition, e.g. "open && isPhone" for a panel that is only modal at small widths. While it is truthy the directive: * remembers the opener and moves focus into the dialog ([data-autofocus], else the first control that is not a "Close" button, else the dialog); * makes everything outside the dialog `inert` - siblings of the dialog and of each ancestor up to . Left alone: aria-live regions (toasts still announce) and a sibling click-to-close backdrop marked data-a11y-backdrop. Where `inert` is unsupported, Tab is trapped instead; * locks page scroll (html overflow) while any dialog is open; * handles Escape and Tab for the top-most dialog wherever focus is, and stops Escape there, so outer dialogs and @keydown.escape.window handlers don't close too. Escape handlers inside the dialog (a dropdown, say) that stop propagation still win; * on close, or removal from the DOM while open, restores inert/scroll state and returns focus to the opener. Nested dialogs stack, including teleported ones: a dialog re-enables its own ancestors if an outer dialog made them inert, inerts only what it found non-inert, and everything unwinds in reverse order. Shadow DOM is not traversed. Registered once per page; repeat includes are harmless. {% endcomment %}
