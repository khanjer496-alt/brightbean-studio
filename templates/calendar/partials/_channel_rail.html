{% comment %} Channel rail on the calendar (WP3). At xl and up: a 16rem column (4.5rem collapsed) left of the grid with "Create post" and "Connect channel", then one row per channel, grouped by account set when the workspace has sets. Below xl the same markup is a horizontally scrolling avatar strip above the toolbar (CSS only, see calendar.html). A row's main part is a toggle button: it adds or removes the channel from the calendar's channel filter (calendarFilters.channels, the same list the Channels dropdown edits) and redraws the grid. A channel that needs reconnecting also gets its own Reconnect button (a POST form to the existing reconnect endpoint), never nested in the toggle. Must sit inside the calendar shell's Alpine scope (calendarApp: isSelected, toggleChannel, clearChannels). Context: workspace, rail_accounts, rail_groups, rail_selected, can_manage_channels, can_create_posts. Collapse state lives in localStorage "channelRailCollapsed" and on (set before first paint by the inline script below, so a collapsed rail never flashes open). {% endcomment %}
