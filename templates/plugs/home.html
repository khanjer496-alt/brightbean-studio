Automations

When a published post reaches a number of likes, reposts or views, repost it or reply under it with a link. Each rule fires once per post, and each account takes only a few automated actions a day. Where a network allows it, another account in this workspace can repost it too, once a person approves.

Automations act as the platform, so the workspace's autonomy policy decides what happens: {% if policy.crisis_paused %}crisis pause is on, so they wait for a person.{% else %}reposts follow “Schedule and publish” ({{ policy.get_publish_level_display }}) and replies follow “Reply” ({{ policy.get_reply_level_display }}). Anything held waits in Activity for approval.{% endif %}
