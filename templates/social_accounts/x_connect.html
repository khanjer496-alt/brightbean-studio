Connect X

X requires every customer to publish through their own X developer app. Set one up once, then paste its keys below.

X bills you for each post

X charges the owner of the developer app per use, on your own X account, not through us. At the time of writing a post costs about $0.015, and a post containing a link about $0.20. Add credits in the X Developer Console and check X's current pricing. If your credits run out, posts fail until you top up.

  1. Open the X Developer Console, sign in and create an app (or open one you already have), and add credits.
  2. In the app's User authentication settings, turn on OAuth 2.0, choose Web App, Automated App or Bot as the type, and set the permissions to Read and write.
  3. Add this as the Callback URI / Redirect URL exactly as shown, then save: {{ callback_url }}
  4. Open Keys and tokens and copy the OAuth 2.0 Client ID and Client Secret into the form below.
  5. Connect. X asks you to authorize the app with these permissions: read and write posts, read your profile, upload media, and stay connected (offline access).
