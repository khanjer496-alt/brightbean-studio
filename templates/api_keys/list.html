API Keys

Agent tokens give an outside AI agent exactly the access you intend: which tools it can use, which accounts it can touch, how much it can do in a day, and whether a person must approve its work.

Connect your AI agent

Use an MCP client or the REST API. Your agent acts within its workspace permissions and the capabilities you choose.

Copy this URL into your client's remote MCP connector. A hosted AI client needs a reachable HTTPS deployment; localhost works only with local clients.

  1. For OAuth-capable clients, sign in and approve access. The consent screen lists what the app asks for in plain language, and you can untick anything before approving.
  2. For token-based clients, issue a token here and add it as a Bearer token in the client's secure settings. The Drafting assistant preset is the safe place to start.
  3. Ask the agent to list available accounts, then create a draft. Review it in the workspace before granting scheduling access.
