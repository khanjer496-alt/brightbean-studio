Connect your AI agent

Use an MCP client or the REST API. Your agent acts within its workspace permissions.

Copy this URL into your client's remote MCP connector. A hosted AI client needs a reachable HTTPS deployment; localhost works only with local clients.

  1. For OAuth-capable clients, sign in and approve access. OAuth uses your own workspace permissions.
  2. For API-key clients, issue a key here and add it as a Bearer token in the client's secure settings. Start with draft-only access by leaving publish_directly disabled.
  3. Ask the agent to list available accounts, then create a draft. Review it in the workspace before granting scheduling access.
